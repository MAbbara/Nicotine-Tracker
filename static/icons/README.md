the pinned `lucide-static` npm package. Lucide is provided under the

rendered through `templates/components/icon.html`. The product macro sets a
consistent 1.75px stroke, round caps/joins, non-focusable SVG behavior, and
the correct accessible-name or decorative-hidden contract.
