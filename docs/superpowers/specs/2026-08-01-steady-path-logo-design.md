# Steady Path Logo Design

## Purpose

Create a new logo for NicotineTracker that feels calm, encouraging, candid, and useful in repeated mobile use. The identity should support reduction and quitting without guilt, clinical styling, or generic health-app tropes.

## Approved direction

The logo uses a compact, rounded pouch/leaf form with a single ascending path cut through it. The path ends in a small terracotta waypoint: progress is framed as the next manageable step rather than a finish line.

The mark must avoid reading as a cigarette, pill, medical cross, or generic analytics chart. The construction should be simple enough to redraw as vector artwork later and remain recognizable at favicon size.

## Deliverables

- Standalone symbol for favicon, app icon, and compact navigation placements
- Horizontal lockup with the symbol and the exact wordmark `NicotineTracker`
- Light-theme version on warm ivory
- Dark one-color version for flexible use
- Square and wide raster exports with generous padding

## Visual system

- Primary: mineral green
- Accent: restrained terracotta waypoint
- Supporting surface: warm ivory
- Geometry: soft, organic, rounded, and editorial
- Wordmark: calm humanist treatment with clear spacing and strong small-size legibility
- Avoid: gradients, neon colors, glossy effects, emoji, medical symbols, shame/failure imagery, and dense detail

## Integration intent

Generated raster assets will be placed in the project’s static asset area without overwriting the existing favicon. The selected asset should be reviewed at both large preview size and small icon size before any consuming template references are changed.

## Acceptance criteria

1. The standalone symbol communicates steady progress without literal nicotine imagery.
2. The horizontal lockup remains legible and balanced at common navigation widths.
3. Light and dark use cases are covered.
4. The symbol is visually coherent with the project’s warm ivory, mineral green, and terracotta design context.
5. No existing asset is overwritten during exploration.
